vLLM 支持的多模态

多模态在 vLLM 中是一等公民：图像、视频、音频统一抽象为 MultiModalInputs。 代表性模型：

家族典型模型模态
LLaVAllava-1.5, llava-onevision, llava-next图像
Qwen-VLQwen2-VL, Qwen2.5-VL图像 / 视频
InternVLInternVL2 / 2.5 / 3图像 / 视频
Llama-VisionLlama-3.2-11B-Vision-Instruct图像
PixtralPixtral-12B图像
Phi-3-Vision, MiniCPM-V—图像
Whisper—音频（转写）
Granite-Speech / Voxtral—音频

完整列表见 官方支持模型表。

调用方式

离线 Python

from vllm import LLM
from PIL import Image

llm = LLM(model="llava-hf/llava-1.5-7b-hf", max_model_len=4096)

# 输入字典：prompt + multi_modal_data
out = llm.generate({
    "prompt": "USER: <image>\n描述这张图。\nASSISTANT:",
    "multi_modal_data": {"image": Image.open("cat.jpg")},
})
print(out[0].outputs[0].text)

OpenAI 兼容 API（图像 URL / base64）

curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen2.5-VL-7B-Instruct",
    "messages": [{
      "role": "user",
      "content": [
        {"type": "text", "text": "图里有几只猫？"},
        {"type": "image_url",
         "image_url": {"url": "https://example.com/cats.jpg"}}
      ]
    }]
  }'

视频

对支持视频的模型（如 Qwen2-VL、InternVL），传 video_url 或本地 mp4； vLLM 内部按帧抽取并交由模型处理。

背后发生了什么

flowchart LR In[输入: text + image/video/audio] P[Multi-Modal Processor\n(vllm/multimodal/)] Tok[Tokenizer\n(text 部分)] Vis[Vision Encoder\n(CLIP/ViT/SigLIP)] Aud[Audio Encoder\n(Whisper/...)] Emb[融合 embedding 序列] LM[语言模型主体] In --> P P --> Tok & Vis & Aud Tok --> Emb Vis --> Emb Aud --> Emb Emb --> LM

关键模块：

  • vllm/multimodal/：注册 image/video/audio processor、token 计数、缓存。
  • vllm/model_executor/models/ 下的多模态模型实现（如 llava.py、qwen2_vl.py）。

Disaggregated Encoder（前沿）

对计算极重的视觉编码器，vLLM 在探索把"图像编码"与"文本生成"解耦到不同进程/不同硬件， 减少编码尖峰对解码 batch 的扰动。详见 docs/features/disagg_encoder.md。

注意事项

  • 显存预算：图像 token 计数往往以"百"为单位，长上下文 + 多图会迅速吃满 KV。
  • 处理器版本：HuggingFace 的 processor 与 tokenizer 版本一定要和模型匹配。
  • 多模态 + chat template：vLLM 默认沿用模型自带 template，自定义时务必正确占位 <image> / <|image|>。
