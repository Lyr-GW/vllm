常见问答 FAQ

📚 参考 · 21/22

启动 / 安装

Q: 装好了运行报 ImportError: ... CUDA？

多半是 PyTorch 与 CUDA driver 版本不匹配。用 python -m vllm collect_env 看 PyTorch 编译时的 CUDA 与 nvidia-smi 里的 driver 版本对照——后者需要 ≥ 前者要求的最低版本。

Q: 用 docker run 启动一会儿 SIGBUS？

共享内存不足。加 --ipc=host 或 --shm-size=8g。

显存 / OOM

Q: 显存够，但启动就 OOM？

vLLM 会"占用 GPU 显存的 90%"用作 KV pool，机器上别的进程会被挤掉。 把 --gpu-memory-utilization 调到 0.8 或更低。

Q: 上下文长度想拉到 128K，但显存不够？

  1. 把 --kv-cache-dtype 改 fp8_e4m3，KV 显存减半；
  2. 加量化（AWQ/GPTQ/FP8）减少权重显存；
  3. 加 TP 把模型切到多卡；
  4. 仍不够则减 --max-model-len 或上 Sequence Parallel。

Q: 我看到大量 num_preemptions_total？

并发太高，KV 不够时就会抢占。降 --max-num-seqs，或加显存 / 量化。

性能

Q: 多卡 TP 没有线性加速？

正常。每层有 all-reduce 通信成本，TP=2 通常 1.7~1.9×，TP=4 大约 3.0~3.5×。 跨 PCIe 比 NVLink 慢得多。也确认 NCCL_DEBUG=INFO 看是否走 P2P。

Q: TTFT 很高？

  • Prompt 巨长 → 开 chunked prefill，注意 --max-num-batched-tokens；
  • 每次 system prompt 都不一样 → Prefix Cache 命不中，看能否把模板部分稳定下来；
  • 第一次启动慢 → CUDA Graph / torch.compile 首次捕获，后续会快。

Q: 怎么完全关闭 CUDA Graph 调试？

--enforce-eager。

功能 / 集成

Q: 怎么和 OpenWebUI / LangChain / LlamaIndex 接？

它们都支持 OpenAI 兼容 API：把 base URL 设成 http://your-vllm:8000/v1、 API key 设成任意字符串（除非你启用 --api-key）即可。

Q: 怎样保证生成的是合法 JSON？

用 结构化输出 的 guided_json， 而不是寄希望于 prompt 工程。

Q: 同一服务能挂多份 LoRA 吗？

能，见 LoRA 多适配器。

Q: 想做 batch 离线推理几百万条，怎么写？

用 LLM.generate(list_of_prompts) 一口气塞进去；vLLM 内部会自动连续批处理。 注意控制 max_tokens，并打开 Prefix Cache 来复用常见前缀。

调试

Q: 跑着跑着输出乱码？

大概率 dtype / 量化与硬件不匹配（如 A100 跑 FP8）。先用 fp16/bf16 验证模型基线，再上量化。

Q: NCCL 卡住怎么办？

开 NCCL_DEBUG=INFO、NCCL_DEBUG_SUBSYS=ALL，看是否在 init 阶段挂死； 云环境上 P2P 不可用时设 NCCL_P2P_DISABLE=1。

Q: 想抓 profile？

VLLM_TORCH_PROFILER_DIR=/tmp/prof vllm serve ...， 然后用 TensorBoard / Chrome trace 看。

项目 / 社区

Q: V0 还是 V1？

新项目直接 V1（V1 是默认）；老脚本可能仍依赖 V0，必要时 VLLM_USE_V1=0 切回。
