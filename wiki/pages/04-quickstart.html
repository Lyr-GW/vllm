快速上手

📖 入门 · 4/22

下面给出两种最常见的用法：离线批量推理和在线 OpenAI 兼容服务。 都默认使用一个公开模型 meta-llama/Llama-3.1-8B-Instruct（你可换成任何 HuggingFace 模型）。

离线批量推理

from vllm import LLM, SamplingParams

prompts = [
    "用一句话解释什么是 PagedAttention：",
    "中国五大淡水湖是哪些？",
    "请把下面这段话翻译成英文：今天天气很好，适合出去散步。",
]
params = SamplingParams(temperature=0.7, top_p=0.95, max_tokens=128)

llm = LLM(
    model="meta-llama/Llama-3.1-8B-Instruct",
    tensor_parallel_size=1,
    gpu_memory_utilization=0.9,
)
outputs = llm.generate(prompts, params)
for o in outputs:
    print("Q:", o.prompt)
    print("A:", o.outputs[0].text)
    print("-" * 40)
关键参数

tensor_parallel_size：本机用几张卡做 TP； gpu_memory_utilization：预分配显存比例（KV Cache 大小由此决定）； max_model_len：手动限制上下文长度可显著节省显存。

聊天接口

from vllm import LLM
llm = LLM(model="meta-llama/Llama-3.1-8B-Instruct")
messages = [
    {"role": "system", "content": "你是一个简洁的中文助手。"},
    {"role": "user", "content": "用 80 字介绍 vLLM。"},
]
out = llm.chat(messages)
print(out[0].outputs[0].text)

chat() 会自动套用模型自带的 tokenizer.chat_template， 比手动拼 prompt 安全得多。

启动 OpenAI 兼容服务

vllm serve meta-llama/Llama-3.1-8B-Instruct \
  --host 0.0.0.0 --port 8000 \
  --tensor-parallel-size 1 \
  --gpu-memory-utilization 0.9 \
  --max-model-len 8192

启动后，下面这些 endpoint 都可用：

  • POST /v1/chat/completions
  • POST /v1/completions
  • POST /v1/embeddings（模型支持时）
  • GET /v1/models
  • GET /metrics（Prometheus 指标）

用 curl 调用

curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "meta-llama/Llama-3.1-8B-Instruct",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": false,
    "max_tokens": 64
  }'

用 OpenAI Python SDK 调用

from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")
resp = client.chat.completions.create(
    model="meta-llama/Llama-3.1-8B-Instruct",
    messages=[{"role": "user", "content": "用一句话夸夸 PagedAttention"}],
    stream=True,
)
for chunk in resp:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)

性能开关速览

开关作用典型默认
--tensor-parallel-size单机 TP 并行1
--pipeline-parallel-size多机/多卡 PP 并行1
--data-parallel-size多 engine 副本 DP1
--gpu-memory-utilization预占显存比例0.9
--max-num-seqs单步并发序列上限256
--max-num-batched-tokens单步 token 上限（影响 chunked prefill）自动
--max-model-len上下文长度上限读自模型
--kv-cache-dtypeauto / fp8_e4m3 / fp8_e5m2auto
--quantizationawq / gptq / fp8 / bitsandbytes / …无
--enable-prefix-caching自动前缀复用V1 默认开
--enable-chunked-prefill长 prompt 分块V1 默认开

常见小问题

  • 模型下载慢？ 设 HF_HUB_ENABLE_HF_TRANSFER=1 + HF_TOKEN，或先 huggingface-cli download。
  • 不想联网？ 设 HF_HUB_OFFLINE=1，把模型本地路径直接传给 --model。
  • OOM？ 优先尝试：减小 --max-model-len → 减小 --max-num-seqs → 加量化 → 加 TP。
