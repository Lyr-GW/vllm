"我想改 xxx，去哪改"

需求入口
加一个新模型vllm/model_executor/models/<your_model>.py + 注册到 __init__.py
加一个新量化方法vllm/model_executor/layers/quantization/ + csrc/quantization/
加一个新 attention backendvllm/v1/attention/backends/
改调度策略vllm/v1/core/sched/scheduler.py
改 KV 管理 / Prefix Cachevllm/v1/core/kv_cache_manager.py
加一个新 OpenAI 端点vllm/entrypoints/openai/
加一个工具调用 parservllm/entrypoints/openai/tool_parsers/
支持新硬件vllm/platforms/ + 对应 attention backend + 必要时插件包
加 reasoning parservllm/reasoning/
加 logits processor 插件vllm/plugins/ 或 SamplingParams.logits_processors
