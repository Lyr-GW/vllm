SamplingParams 核心字段

字段含义
n每条 prompt 生成多少条候选
best_of内部候选数（旧字段，OpenAI 兼容用）
temperaturesoftmax 温度，0 = greedy
top_p核采样阈值
top_k截断 token 数
min_p相对最大概率的最小阈值
repetition_penalty / presence_penalty / frequency_penalty抑制重复
max_tokens最大生成长度
min_tokens最小生成长度（生成不足时强制忽略 EOS）
stop / stop_token_ids停止串 / 停止 token
logprobs返回 top-N 的对数概率
seed随机种子（可复现）
use_beam_searchBeam Search
guided_*结构化输出（见下）

结构化输出

vLLM 集成 XGrammar 与 Outlines，可以在 decode 时 实时把 logits mask 成只允许"合法 token"，从而保证输出 100% 符合给定模式。

Guided JSON

from vllm import LLM, SamplingParams
from pydantic import BaseModel

class Person(BaseModel):
    name: str
    age: int
    hobbies: list[str]

llm = LLM(model="<your-model>")
params = SamplingParams(
    temperature=0.7,
    max_tokens=200,
    guided_decoding={"json": Person.model_json_schema()},
)
out = llm.generate(["请给我一个示例人物的 JSON："], params)
print(out[0].outputs[0].text)   # 一定是合法 JSON，且符合 schema

Guided Regex / Choice / Grammar

SamplingParams(guided_decoding={"regex": r"\d{4}-\d{2}-\d{2}"})
SamplingParams(guided_decoding={"choice": ["positive", "negative", "neutral"]})
SamplingParams(guided_decoding={"grammar": open("my.lark").read()})  # EBNF / Lark

API 端用法

OpenAI 风格的 response_format：

{
  "model": "...",
  "messages": [...],
  "response_format": {"type": "json_object"}
}

或者使用 vLLM 扩展字段：

{
  "extra_body": {"guided_json": {...schema...}}
}

Beam Search / Best-of

Beam Search 在 vLLM 中以 parallel sampling + 重写过程 实现， 开销低（KV 共享 + CoW）。但对话场景多数情况下 nucleus / min-p 已足够，beam search 适合 NMT、摘要等结构化任务。

Logits Processors（自定义）

vLLM 允许用户提供一个 LogitsProcessor 函数：

def disallow_word(logits, token_ids):
    bad = tokenizer.convert_tokens_to_ids("禁词")
    logits[..., bad] = -float("inf")
    return logits

params = SamplingParams(logits_processors=[disallow_word])

更进阶的玩法（自定义采样器 / 插件）见 docs/design/logits_processors.md。

调参 cheat sheet

  • 事实问答 / 翻译 / 代码：temperature=0 或 0.2，可加 top_p=0.9。
  • 开放聊天：temperature=0.7~0.9，top_p=0.95，min_p=0.05。
  • 避免重复：repetition_penalty=1.05~1.2，过高反而生硬。
  • 固定格式：直接上结构化输出，比纯 prompt 工程稳得多。
