术语表

📚 参考 · 22/22

本表给出本 Wiki 与 vLLM 上下文里反复出现的术语的中文简释 + 英文标准写法。 按字母 / 拼音排序，找不到时直接 Ctrl+F。

A — F

All-Reduce
把所有进程的张量求和并广播回每个进程的集合通信原语。vLLM 用 NCCL， 也有自研 Custom All-Reduce 用于小消息低延迟。
AutoRound
一种基于"舍入学习"的极低比特量化方法，常用于 4/3/2-bit。
AWQ (Activation-aware Weight Quantization)
4-bit 权重量化方法，按通道选择保留精度高的权重，质量优于纯 GPTQ。
Backend
vLLM 里 attention/通信/采样等可替换实现。例如 attention backend 有 FlashAttention2/3、FlashInfer、XFormers、Triton 等。
Beam Search
同时保留 k 个最高累积概率的候选，逐步扩展。
Block
PagedAttention 中 KV 缓存的最小分配单位，默认 16 个 token。
Chunked Prefill
把长 prompt 的 prefill 切成多块，与正在 decode 的 seq 混 batch。
Continuous Batching
以 iteration 为单位重新选择 batch 成员，请求随到随入。
Copy-on-Write (CoW)
共享一个块直到要写入时再拷贝。vLLM 用 CoW 在 beam search / 并行采样里复用前缀块。
CUDA Graph
把一段固定形状的 GPU 计算"录"成 graph，后续以一次 launch 重放，减少 host 开销。
DCO (Developer Certificate of Origin)
提交者声明自己有权贡献代码的轻量协议，git commit -s 自动加。
Decode
自回归生成阶段：每步仅算 1 个新 token，但需要访问全部历史 K/V。
EAGLE
一类基于隐藏态的轻量 draft 网络，用于投机解码。
EOS (End-Of-Sequence)
序列结束 token，遇到则该 seq 完成。
EP (Expert Parallelism)
把 MoE 的不同 expert 放到不同设备。
FP8
8-bit 浮点格式，常见 E4M3（更高精度）与 E5M2（更大范围）。Hopper / MI300 原生支持。

G — N

GPTQ
基于 Hessian 信息逐层量化的方法，常见 4-bit per-group。
Goodput
满足延迟 SLA 的吞吐量。
HBM
High Bandwidth Memory，GPU 显存。
Hybrid KV Cache
V1 中支持不同层用不同形状的 KV 缓存（如 Mamba+Attention 混合架构）。
ITL (Inter-Token Latency)
相邻两个输出 token 之间的间隔。
KV Cache
缓存历史 token 的 Key/Value 张量以避免重算。
LoRA
低秩适配，把对 W 的更新写成 BA 的乘积形式。
Marlin / Machete
vLLM 中两种高性能量化 GEMM kernel 实现。
Medusa
在主模型上加多个输出头进行投机预测的方法。
MoE (Mixture-of-Experts)
每个 token 只激活若干 expert，参数总量大但单 token 算力小。
NCCL
NVIDIA 的 GPU 集合通信库。

P — Z

PagedAttention
vLLM 核心创新：用块表把 KV 缓存按块管理。
PP (Pipeline Parallelism)
把不同层放到不同设备形成流水线。
Preemption
资源不足时让某些 seq 暂时退出，后续以 Recompute 或 Swap 恢复。
Prefill
对 prompt 一次性计算 K/V。
Prefix Caching
自动复用相同前缀的 KV 块，命中后 prefill 时间近乎为 0。
Recompute
抢占恢复时丢弃 KV 重新 prefill。
SP (Sequence Parallelism)
把同一条 sequence 的 token 维度切分到多设备，支撑超长上下文。
Speculative Decoding
用 draft 模型一次预测多个 token，target 模型一次验证。
SSE (Server-Sent Events)
HTTP 流式协议，OpenAI API 的流式响应使用它。
Swap
抢占恢复时把 KV 从 GPU 拷到 CPU 内存暂存。
TP (Tensor Parallelism)
把每层权重矩阵按维度切到多设备。
TPOT (Time Per Output Token)
每个输出 token 的平均时间。
TTFT (Time To First Token)
请求到达到首 token 输出之间的时间。
V0 / V1
vLLM 的两代引擎实现，新功能优先落地于 V1。
XGrammar
基于上下文无关文法 / EBNF 的高性能结构化输出 mask 引擎。

找不到某个术语？欢迎到本 Wiki 仓库提 PR 补充。
